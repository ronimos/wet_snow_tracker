## Input Formats

### 1. SNOWPACK Profile Files (.pro)

**File Extension:** `.pro`  
**Location:** `data/input/*.pro`  
**Format:** Text file with header section and data section

#### Header Section

```
[HEADER]
StationName=Example_Station_N
Latitude=40.12345
Longitude=-105.67890
Altitude=3500
SlopeAngle=35.0
SlopeAzi=180.0
Easting=1234567.89
Northing=9876543.21
```

**Required Fields:**
| Field | Type | Unit | Description | Example |
|-------|------|------|-------------|---------|
| StationName | string | - | Unique identifier | `Summit_N` |
| Latitude | float | degrees | Decimal degrees | `40.12345` |
| Longitude | float | degrees | Decimal degrees | `-105.67890` |
| Altitude | integer | meters | Elevation above sea level | `3500` |
| SlopeAngle | float | degrees | Slope inclination (0=flat, 90=vertical) | `35.0` |
| SlopeAzi | float | degrees | Aspect azimuth (0=N, 90=E, 180=S, 270=W) | `180.0` |

**Aspect Calculation Logic:**
```python
if SlopeAngle == 0.0:
    aspect = 'flat'
elif SlopeAzi == 0.0:
    aspect = 'N'
elif SlopeAzi == 90.0:
    aspect = 'E'
elif SlopeAzi == 180.0:
    aspect = 'S'
elif SlopeAzi == 270.0:
    aspect = 'W'
else:
    aspect = f"Azi_{SlopeAzi}"
```

#### Data Section

```
[DATA]
0500,0501,0502,0503,0506,0507,0512,0508,0509,0510,0511,0514
01.10.2024 00:00,0.00,350.0,268.15,0.00,200,0.50,0.00,0.00,0.00,0.00,0
01.10.2024 00:00,0.05,320.0,268.45,0.00,210,0.60,0.10,0.05,1.00,0.10,0
...
```

**Parameter Codes:**
| Code | Name | Unit | Description |
|------|------|------|-------------|
| 0500 | timestamp | datetime | Date and time of measurement |
| 0501 | height | m | Height of layer above ground |
| 0502 | density | kg/m³ | Snow density |
| 0503 | temperature | K | Layer temperature |
| 0506 | lwc | volumetric | Liquid water content (0.0-1.0) |
| 0507 | grain_type | code | Grain classification code |
| 0512 | grain_size | mm | Mean grain diameter |
| 0508 | dendricity | - | Dendricity parameter |
| 0509 | sphericity | - | Sphericity parameter |
| 0510 | coord_number | - | Coordination number |
| 0511 | bond_size | - | Bond size parameter |
| 0514 | hardness | - | Layer hardness |

**Grain Type Codes:**
| Range | Description |
|-------|-------------|
| 100-199 | Precipitation particles |
| 200-299 | Decomposing and fragmented particles |
| 300-399 | Rounded grains |
| 400-499 | Faceted crystals |
| 500-599 | Depth hoar |
| 600-699 | Surface hoar |
| 700-799 | Melt forms |
| 800-899 | Ice formations |

**Example .pro File:**
```
[HEADER]

Latitude=40.5
Longitude=-105.2
Altitude=3200
SlopeAngle=30.0
SlopeAzi=0.0

[DATA]

15.05.2025 00:00,0.00,300.0,273.15,0.00,200,0.5
15.05.2025 00:00,0.10,280.0,272.50,0.01,210,0.6
15.05.2025 00:00,0.50,250.0,271.80,0.03,400,1.2
15.05.2025 06:00,0.00,305.0,274.00,0.02,200,0.5
...
```

## Configuration Formats

### param_config.py Structure

```python
from pathlib import Path
from dataclasses import dataclass

@dataclass
class Paths:
    """File system paths"""
    base_path: Path
    input_path: Path
    reference_path: Path
    results_path: Path
    assets_path: Path

class AnalysisParams:
    """Analysis parameters"""
    days_before: int = 7
    days_after: int = 7
    lwc_threshold: float = 0.04
    min_gs_difference: float = 0.5

@dataclass
class PlotParams:
    """Plotting parameters"""
    figsize: tuple = (14, 8)
    dpi: int = 300
    thumbnail_size: tuple = (800, 534)

class Config:
    """Main configuration"""
    def __init__(self):
        self.paths = Paths(...)
        self.analysis = AnalysisParams()
        self.plot = PlotParams()

# Global instance
config = Config()
```

## Data Type Specifications

### Aspect Values

**Valid values:**
- `'N'` - North (0° ± 22.5°)
- `'E'` - East (90° ± 22.5°)
- `'S'` - South (180° ± 22.5°)
- `'W'` - West (270° ± 22.5°)
- `'flat'` - Flat terrain (SlopeAngle = 0)
- `'Azi_XXX'` - Non-cardinal (where XXX is exact azimuth)

### Time-to-LOC Values

**Meaning:**
- `Positive (e.g., 24.5)` - LOC will be reached in 24.5 hours from reference date
- `Negative (e.g., -12.0)` - LOC was reached 12 hours before reference date
- `NaN / None` - Wetting front doesn't reach LOC in analysis window
- `0.0` - Wetting front at LOC exactly at reference date

### LWC Units

**In .pro files:** Volumetric (0.0 to 1.0)
- `0.00` = Dry (0%)
- `0.01` = 1% volumetric
- `0.04` = 4% volumetric (default threshold)

**In outputs:** Percentage (0 to 100)
- `0.0` = Dry (0%)
- `1.0` = 1% volumetric
- `4.0` = 4% volumetric

**Conversion:**
```python
lwc_percent = lwc_volumetric * 100.0
```

### Color Codes

**Map polygon colors:**
| Color | Hex | RGB | Condition |
|-------|-----|-----|-----------|
| darkred | #8B0000 | (139,0,0) | time_to_loc: 0-24h |
| orange | #FFA500 | (255,165,0) | time_to_loc: 24-48h |
| yellow | #FFFF00 | (255,255,0) | time_to_loc: 48-72h OR avg_lwc: 1-3% |
| red | #FF0000 | (255,0,0) | time_to_loc: -24-0h OR avg_lwc: >3% |
| lightblue | #ADD8E6 | (173,216,230) | time_to_loc: -48--24h |
| darkblue | #00008B | (0,0,139) | time_to_loc: -72--48h |
| gray | #808080 | (128,128,128) | No data / unknown |

## Data Validation

### Required Checks

**For .pro files:**
```python
# Header validation
assert all(key in metadata for key in [
    'latitude', 'longitude', 'altitude', 
    'stationname', 'slopeangle', 'slopeazi'
])

# Data validation
assert -90 <= latitude <= 90
assert -180 <= longitude <= 180
assert altitude > 0
assert 0 <= slopeangle <= 90
assert 0 <= slopeazi < 360
```

**For analysis results:**
```python
# LWC validation
assert 0 <= avg_lwc_above_loc <= 100 or avg_lwc_above_loc is None

# Time validation  
assert time_to_loc is np.nan or isinstance(time_to_loc, (int, float))

# Geometry validation
assert polygon.is_valid
assert polygon.area > 0
```

## Common Data Issues

### Issue: Invalid LWC values

**Symptom:** LWC > 1.0 in .pro file  
**Cause:** Unit confusion (% vs volumetric)  
**Fix:** Convert: `lwc_volumetric = lwc_percent / 100.0`

### Issue: Missing timestamps

**Symptom:** Gaps in time series  
**Cause:** SNOWPACK output frequency  
**Fix:** Expected - analysis handles irregular timestamps

### Issue: Duplicate entries

**Symptom:** Same timestamp appears multiple times  
**Cause:** Model restart or output error  
**Fix:** Keep last occurrence or flag for manual review

### Issue: Polygon overlap

**Symptom:** Multiple polygons cover same area  
**Cause:** Improper aspect splitting  
**Fix:** Check aspect angles, ensure clean splits

## Example Data Workflow

```python
# 1. Load .pro file
profile = SnowpackProfile("data/input/station_N.pro")

# 2. Get time series summary
summary = profile.get_full_timeseries_summary(
    parameters_to_calculate={
        "hs": get_total_snow_depth,
        "avg_lwc_above_loc": lambda df: avg_lwc_above_weak(df, find_weak_layer)
    },
    start_date="2025-05-01",
    end_date="2025-05-31"
)

# 3. Extract specific date
reference_date = datetime(2025, 5, 15, 12, 0)
avg_lwc = summary.loc[reference_date, 'avg_lwc_above_loc']

# 4. Store in result
result = {
    "avg_lwc_above_loc": float(avg_lwc) if pd.notna(avg_lwc) else None,
    "time_to_loc": calculate_time_to_loc(summary, reference_date)
}

# 5. Use for coloring
color = get_polygon_color(
    result['time_to_loc'],
    result['avg_lwc_above_loc']
)
```
